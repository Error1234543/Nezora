# Mehndi by Ekta

Demo mehndi booking website for Vadodara.

- Customer website: repository root redirects to `/mehndi/`.
- Booking page: `mehndi/index.html`
- Demo admin dashboard: `mehndi/admin/`

**Demo only:** bookings use localStorage in the same browser. Payments are simulated; no real payment is collected. Not production-ready.

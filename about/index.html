THE IDEA BEHIND SONIC

Play. Learn.
Create.

SONIC Universe is an evolving digital playground that brings small games, practical tools, quick learning and creative helpers together in one place.

Accessible

Core experiences should work on mobile and desktop, without forcing visitors to create an account.

Useful

Fun is better when it comes with something practical to learn, make or solve.

Growing

New games, tools and community features can be added in small, tested steps.

Roadmap

Phase 1: Static website, browser games and local tools — included now.

Phase 2: Secure authentication, database-backed profiles and synced scores.

Phase 3: Real multiplayer, moderated public community and expanded creator tools.

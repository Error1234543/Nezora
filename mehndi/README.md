# Mehndi by Ekta — Demo v1.0

This is a separate demo microsite inside the existing Nezora repository. The original SONIC Universe homepage and other folders are left unchanged.

## Open
- Customer website: `/mehndi/`
- Demo admin: `/mehndi/admin/`

## Included
- Premium cream + gold, mobile-first design
- Home Visit (₹1,200 / ₹1,500 / ₹2,000) and Visit Ekta (₹500)
- Booking request form with date and preferred time window
- Demo 10 km distance input check for home visits
- WhatsApp share link for booking request
- Separate admin preview to assign exact appointment time, simulate 30% advance, confirm or cancel
- Browser-local demo storage

## Demo-only limitations
- No real payment gateway or money collection
- No server/database; customer and admin data exist only in the same browser's localStorage
- No secure admin authentication
- Distance validation is a user-entered demo estimate, not a real map/geocoding calculation
- Replace image choices and add verified business contact/location details before launch

Do not use this demo to collect real customer personal data or payments.
